# 安全基线

## 执行隔离

- 每个任务独立工作目录，路径解析限制在 `workspace-root` 下。
- Gateway 仅接受命令白名单，`NodeCommandRequest` 中的参数需通过严格正则校验。
- 禁止调用方传入绝对路径、`..`、Shell 元字符或任意命令字符串。
- 生产环境使用 TLS/mTLS 或短期令牌；回调必须验签并防重放。

## 凭据

- 模型 API Key、Git/SVN 凭据、Gateway Token 通过环境变量或密钥管理注入。
- 不记录 Token、带密码的仓库 URL、SVN 凭据。
- Agent 运行时不下发生产密钥与生产数据库凭据。

## 数据

- BUG 附件与日志入库前做大小限制、病毒扫描与敏感信息脱敏。
- 日志正文存文件/对象存储，数据库只存索引、摘要与校验值。

## 审批

| 操作 | 默认 |
|---|---|
| 读取代码、执行测试 | 自动 |
| 本地 commit | 自动（可配置） |
| Git push / MR | 审批 |
| `git svn dcommit` | 审批 |
| 测试环境部署 | 项目授权后自动 |
| 生产部署 | 必须人工审批 |
